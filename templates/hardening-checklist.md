# Hardening Checklist

- [ ] Scope, threat model, and baseline approved
- [ ] Supported release and repositories verified
- [ ] Backup and console recovery tested
- [ ] Named administration, MFA, PAM, sudo, and SSH validated
- [ ] Listeners and firewall flows matched to the matrix
- [ ] Unused packages, services, sockets, and jobs reviewed
- [ ] Kernel, mount, and module policy tested
- [ ] SELinux or AppArmor enforcing
- [ ] Cryptography, certificates, and secrets inventoried
- [ ] auditd, journald, time, forwarding, and alerting validated
- [ ] Vulnerability and configuration findings dispositioned
- [ ] Restore and incident procedures exercised
- [ ] Evidence signed; exceptions have owners and expiry dates
