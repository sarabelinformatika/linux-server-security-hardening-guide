# Primary Sources

Use the documentation matching the exact installed release. Accessed 2026-10-22.

## Standards and baselines

- [NIST SP 800-123: Guide to General Server Security](https://csrc.nist.gov/pubs/sp/800/123/final)
- [NIST SP 800-53 Rev. 5: Security and Privacy Controls](https://csrc.nist.gov/pubs/sp/800/53/r5/upd1/final)
- [NIST SP 800-128: Security-Focused Configuration Management](https://csrc.nist.gov/pubs/sp/800/128/upd1/final)
- [CIS Benchmarks](https://www.cisecurity.org/cis-benchmarks)
- [ANSSI configuration recommendations for GNU/Linux systems](https://cyber.gouv.fr/publications/configuration-recommendations-gnulinux-system)

## Core components

- [OpenSSH manual pages](https://www.openssh.com/manual.html)
- [nftables wiki](https://wiki.nftables.org/wiki-nftables/index.php/Main_Page)
- [systemd manual pages](https://www.freedesktop.org/software/systemd/man/latest/)
- [SELinux Project documentation](https://selinuxproject.org/page/Main_Page)
- [AppArmor documentation](https://apparmor.net/)
- [Linux kernel admin guide](https://docs.kernel.org/admin-guide/)
- [OpenSCAP user manual](https://static.open-scap.org/openscap-1.3/oscap_user_manual.html)

The older Debian Securing Manual contains useful historical material but is not treated here as a current normative baseline. Prefer current Debian security notices, release documentation, package metadata, and component manuals.
