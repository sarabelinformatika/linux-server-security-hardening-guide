# Security Policy

## Supported versions

Security corrections are applied to the current release line documented in [SUPPORTED_VERSIONS.md](SUPPORTED_VERSIONS.md).

## Reporting

Do not open a public issue for a vulnerability or exposed secret. Contact [SARABEL Informatika](https://sarabelinformatika.hu) through its published secure business contact channel and include the affected file or release, impact, reproduction details, and suggested mitigation. Do not include real credentials, customer data, or exploit activity against systems you do not own.

This repository contains guidance and read-only assessment scripts; it does not provide emergency incident-response coverage.
